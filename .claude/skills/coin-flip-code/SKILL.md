# Coin Flip (Script)

Run the `scripts/flip.py` script in this skill's directory with Python and report the output as the result: `python3` on macOS and Linux; on Windows, `py -3`, or `python` if `py` is missing (there, `python3` is usually the Microsoft Store placeholder, not Python).
